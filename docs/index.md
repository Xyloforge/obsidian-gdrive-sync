# Xyloforge Notes Sync

A small personal Obsidian plugin that syncs an Obsidian vault with a folder in the user's own Google Drive, on desktop and Android.

- Source code: [github.com/Xyloforge/obsidian-gdrive-sync](https://github.com/Xyloforge/obsidian-gdrive-sync)
- [Privacy policy](privacy.html)

Not affiliated with Obsidian or Google.
